# Watower releases

Official Watower release files are published here by IA Compa.

Visit [Watower](https://iacompa.com/apps/watower) for macOS downloads, features, privacy, and support. Watower is free and open source under the MIT license.

## Downloads

[Download Watower 1.1 for Mac](https://github.com/iacompa/watower-releases/releases/download/v1.1.0/Watower-1.1.0-macOS-arm64.dmg). Requires macOS 14 or later and Apple silicon. The app and DMG are Developer ID signed and notarized by Apple.

The [release page](https://github.com/iacompa/watower-releases/releases/tag/v1.1.0) includes the DMG, ZIP, matching source archive, release notes, and SHA-256 checksums.

## Matching source

Each app release includes a separately named `Watower-<version>-source.tar.gz` asset with its matching app source, build instructions, MIT license, and notices. Use that asset for the corresponding source.

GitHub's automatically generated **Source code (zip)** and **Source code (tar.gz)** downloads contain only this release-hosting repository. They are not the app's matching source archive.

## Security

Report vulnerabilities through [private vulnerability reporting](https://github.com/iacompa/watower-releases/security/advisories/new). See [SECURITY.md](SECURITY.md).
