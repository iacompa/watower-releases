## Matching source

Use the separately uploaded source archive for the app's corresponding source. See [CORRESPONDING_SOURCE.md](CORRESPONDING_SOURCE.md) for contents, build instructions, and platform limits.

GitHub's automatically generated **Source code (zip)** and **Source code (tar.gz)** downloads contain only this release-hosting repository. They do not contain the app's matching source.
