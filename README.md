## Matching source

Use the separately uploaded source archive together with the directly downloadable [companion source and rebuild guide](https://github.com/iacompa/watower-releases/releases/download/v1.4/CORRESPONDING_SOURCE.md). The companion is supplied beside the archive and supplements its frozen instructions.

GitHub's automatically generated **Source code (zip)** and **Source code (tar.gz)** downloads contain only this release-hosting repository. They do not contain the app's matching source.
