# Security Policy

Watower's whole value is that its trust claims hold. If you find a way to break one, we want to hear about it — privately first, so users aren't exposed while we fix it.

## Reporting a vulnerability

- **Preferred:** GitHub [Private Vulnerability Reporting](https://github.com/iacompa/watower-releases/security/advisories/new) on the public releases repository.
- **Alternative:** email `apps@iacompa.com` with "SECURITY" in the subject.

Please include steps to reproduce, the affected version or commit, and your assessment of impact. We'll acknowledge within a few business days.

## Supported versions

The **latest release** receives security fixes. Older versions are not patched — the update path is to upgrade.

## Coordinated disclosure

We follow a **90-day coordinated disclosure** window: report privately, we fix and release, then details go public — earlier if a fix ships sooner, or by mutual agreement if a fix genuinely needs more time. We will not use disclosure timelines to sit on problems.

## Credits

Reporters are credited by name (or handle, or anonymously — your choice) in the release notes and the advisory. There is no bug bounty at this time; Watower is a free product from a small company, and we say so plainly rather than imply rewards we can't pay.
